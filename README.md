# Подсветка МотоХаб — готовые файлы

Боковая подсветка для электромотоцикла Tinbot RS1: контроллер Gledopto GL-C-016WL-D (ESP32), две ленты WS2815 12 В,
модуль оптопар PC817 на 4 канала для поворотников и замка зажигания.

Здесь только готовые файлы для установки:

- **«Тест подсветки»** — приложение Android для проверки и настройки (`motohub-lights-test.apk`).
- **Прошивка** для контроллера:
  - `motohub-lights-3.2.0-gl016.bin` — для первой прошивки по USB-C (адрес **0x0**, страница esptool-js);
  - `motohub-lights-ota-3.2.0-gl016.bin` — для обновления по Bluetooth из приложения;
  - файлы `…-devkit.bin` — для самодельной платы на ESP32 DevKit (не для Gledopto).
- **Инструкция** (PDF) и **схема подключения**.

Скачать — в разделе [Releases](https://github.com/ivalushin0/motohub-lights/releases/latest).

Приложение само проверяет обновления: на первом экране «Проверить обновления» — скачает новое приложение и новую прошивку;
прошивка ставится кнопкой «Прошить для Gledopto» в первом пункте проверки.

`latest.json` — номер последней версии для приложения; папка `files` — те же файлы для зеркала jsDelivr (если GitHub у оператора заблокирован).
